# GEODEV LAB PROJECT

Identifies which settlements in Abuja Municipal Area Council (AMAC) underlay 200m of a waterway,  to help residents, visitors and planners see which areas are potentially exposed to flooding.

**GeoDev Lab Africa, Cohort One.** Joyce Nomigo

---

## The question

Which areas in AMAC underlay  200m of a watercourse?.
